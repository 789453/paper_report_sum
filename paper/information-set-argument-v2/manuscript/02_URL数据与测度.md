# 第二章 URL数据与测度：微观信息获取为什么能够被观察

## 2.1 美国2007年浏览面板：来源、招募与覆盖

本文使用美国居民家庭在2007年1、2、3、6月的浏览记录。原始面板包含数万户、约20亿条带时间戳的URL，来自一家未具名的线上研究公司。记录以家庭为索引，包含URL、访问时点、页面活动时间和粗内容分类。数据商名称未公开，研究者取得的是经供应商匿名处理的浏览轨迹。

数据来自招募后安装的浏览插件，并非问卷回忆出的“我每天研究多久”。供应商通过随机拨号等方式招募家庭，努力使人口构成接近总体，并在家庭规模、生命阶段和地域等方面平衡样本；参加者接受小额激励并同意记录浏览活动。家庭所有电脑的记录被汇总，供应商去除账户号码等可识别信息。这提供了跨网站行为轨迹，也带来明确的分析单位：论文称其为individual investors，实际追踪单位是家庭，无法保证每次访问都来自同一位家庭成员。

在这套面板中，作者识别至少进行过一笔美国普通股或ADR交易的家庭，得到484户、2911笔交易。筛选后的家庭浏览记录约850万条，覆盖约6万小时互联网使用。八家券商域名出现在其活动中，其中七家有可识别交易，另有二十余个券商外的财经来源。这里的跨域名覆盖很重要：如果一户在Yahoo查看分析师信息，随后返回券商交易，研究活动不必被截断在账户网站之外。

URL可以识别部分下单与交易活动，包括股票、方向，有些还包含股数；在191户可识别规模的家庭中，作者结合市场数据估算交易金额。研究因此可以与具体行动连接。但记录没有提供完整投资组合，持仓、组合暴露与统一绩效分析仍是数据缺口。

2007年电脑面板与今天的手机、推送和社交环境不同。作者用历史和当代网页比较，说明部分基本信息菜单延续至今，这有助于理解记录内容；它没有验证投资者在不同年代的信息配置完全相同。对本报告而言，这些数据最直接回答的是当时美国在线股票交易家庭的研究过程。其方法及提出的问题可以迁移，具体比例是否适用于今天仍应另行检验。

## 2.2 从页面地址读出股票和内容：两个原文案例

URL之所以有用，是因为它往往同时保留页面所属站点、内容路径和查询参数。单看域名只能知道进入了哪家网站；继续读取路径和参数，才可能知道研究了哪只股票、哪类内容，以及某些展示设置。下面采用原文公开的地址及Table IA1的原始格式。IA1是作者构造的浏览示例，并非公开的匿名微观样本；因此可以用来讲识别方法，不能用来估计研究时间分布。

第一个例子是分析师意见页面：

```text
http://finance.yahoo.com/q/ao?s=IMCL
       └── Yahoo Finance ──┘ │ └─ 股票IMCL
                             └── ao：分析师意见页面
```

股票代码直接出现在`s`参数中，`ao`的含义则由历史网页归档核验为analyst opinions。处理后的研究对象是“这一户在某时访问IMCL的分析师资料”，比网站访问多了股票和主题两层内容。时间戳与活动时间再使它进入该户的内容参与统计、研究时间统计和事件前后的排序。历史网页核验把URL语法与经济类别连接起来。

第二个例子来自券商盈利图表页面，股票IMCL由相邻链接补充识别：

```text
.../stocks/earnings/update_earningsChart.asp?
showQTRChange=1&display=mountain&overlay=&
indicator=volume,1,13,EMA,13&duration=1095&daysforward=545&year=2006
```

路径表明盈利内容，`duration=1095`与`daysforward=545`分别对应约三年历史与约一年半前瞻。附加参数还显示成交量和移动平均等内容。一个链接因而可能承载多个信息对象；把整段时长分别完整记给各个主题，会夸大总投入。附录的处理是先拆股票、再拆可辨主题，均分原链接活动时间，保证所有副本合计等于原时长。这个分配识别的是展示所含信息，不能测到眼睛在各块内容上实际停留多久。

两例共同解释了数据增量：前者把粗网站访问细化为股票与主题，后者进一步揭示展示窗口和复合内容。高分辨率既增加了可观察信息，也增加了研究者必须作出的分类选择。

下面保留IA1的连续片段，使跨站研究与非研究活动的界线可以被直接看到。为便于阅读，仅缩短公共路径；时点与地址特征据原表摘录，没有补造活动时长。

|原表行|2007-03-23时间|页面特征|能够识别的对象|
|---:|---|---|---|
|10|14:39:20|Yahoo `q?s=IMCL`|IMCL综合行情|
|11|14:39:25|Business Wire新闻地址，不含ticker|确定为新闻，股票需上下文|
|12|14:39:29|Yahoo `q?s=IMCL`|再次进入IMCL行情|
|13|14:39:32|Yahoo `q/ao?s=IMCL`|IMCL分析师意见|
|14|14:40:52|赛车网站|非研究活动|

第11行由相同的单一股票在前后夹定，满足附录补配规则。它说明为什么仅丢弃缺ticker的链接会漏掉研究，也说明为什么不能把任意相邻新闻都归到某只股票。表中时间用于解释顺序；论文实际活动时间字段不在IA1中展示，不把相邻时差直接冒充已测注意力。

## 2.3 从研究到交易：可见记录与时间归属

交易记录为研究轨迹提供了行动锚点。原文的一个订单地址为：

```text
.../invest/socreateentry?ordertype="sell"&symbol=GOOG&shares=100
                             卖出          股票       股数
```

作者先利用订单关键词定位候选记录，再检查链接序列与网站语法。相同股票、相同方向、间隔不超过30分钟的候选交易点击合并为一次，以序列中最后一次的时点代表该次交易。这样可减少确认页、连续点击或接近的操作把交易数膨胀的风险。浏览会话的15分钟间隔则界定浏览活动的连续段，两套阈值分别服务于交易合并和浏览分段。

研究归属还需要另一条规则。对于同一家庭、同一股票，作者把研究时间分配给其后的下一笔交易；没有后续交易时，计为交易后研究。每笔交易之前的累积，从样本起点或上一笔同股交易之后开始。

```text
同一家庭、同一股票的时间轴（方法示意，不是样本记录）

上一笔同股交易 ── 研究活动 ── 研究活动 ── 下一笔同股交易 ── 后续研究
                └──── 归给下一笔交易 ────┘
若其后不再出现同股交易，最后一段归为交易后研究。
```

因此，某条研究记录是否属于交易前，不由一次普通浏览会话的边界决定，而由同股交易序列决定。这个设计使后文能够比较研究在交易前何时累积；它也使交易归属、浏览会话和十天融合路径三个时间概念保持区分，后者将在路径分析时再介绍。

经过这些识别，我们得到带有家庭、股票、内容和时间的研究记录，以及可以连接的交易事件。原论文的四维组织正是利用这些字段保留的结构：

|记录中保留的内容|可以回答的问题|测量维度|
|---|---|---|
|活动时间，家庭标识|一户投入多少研究资源|Depth，投入|
|统一后的页面与经济主题|资源被配置给哪些信息|Topics，内容|
|家庭与股票两个索引|总体结构在哪些家庭、哪些标的间不同|Heterogeneity，差异|
|时间戳及同股交易事件|研究何时发生、怎样依次接近行动|Timing，时点与顺序|

四个维度在同一套明细上取不同的聚合与比较，既保留高维对象，也使全篇能够组织起来。接下来的困难转为如何比较：家庭留在面板中的月份不同，交易次数不同，部分研究还无法匹配股票。下一章先解决这些统计差别，再呈现研究资源的规模与内容分布。
