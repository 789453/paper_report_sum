# 投资者与交易情境（N33–39）

对应 R33–R40。N33 从股票月换到投资者（家庭），保留交易笔数相关 −.10/秩相关 −.22；口述只将其用作风格分析动机。PCA 概括同一投资者的主题参与及股票倾向的主要变异方向，不是把 Y 换掉再回归。

N34“PCA 输入：主题参与与投机标的倾向”，公式 B_ik=1{m_ik>2}；i 是投资者，k 是主题，m 是该投资者在主题上的月均研究分钟，先跨匹配到的股票加总。表格三行 A/B/C，列为价格图、盈利、股利、分析师、…以及连续 S。主题格只填 0 或 1，表上方清楚标“教学构造例，非实际微观记录”。0/1 的组合不解释成原样本关联；S 用符号 S_A 等，避免伪造数值。实际输入是 13 个主题列+1 个连续标的倾向，不能让人以为最后一列也是指示量。投机倾向高/低只用小、新、高波动/大、成熟、分红一句解释，删除风险统计过少、得分差异等旁支。

N35 标题和正文都明确“第一主成分 PC1”，展示的是降维载荷；所有主题正载荷、投机标的倾向近零，解释 26.81%。删“选列展示”句。N36 同样明确“第二主成分 PC2”，保留 8.77%、正负两侧、快信息与投机标的同向、盈利/股利在反侧；删读图口令及末尾因果防御句，保留“主题与标的的联合变异”。这两页无需声称它们是回归系数。

N37 Figure 3 保留均值/中位数图，屏幕标同股交易前研究。0 是订单时点，累计分钟与横轴小时保持。中位数约在前五天才见累积，最陡增量靠近下单；不说所有人都从第五天开始看。

N38 Figure 4 保留入口、END、Further 及压缩教学例，删除用户指定的“原路径重复主题已删除”半句。压缩例仍解释重复价格图不会生成新节点；END 是没有新增计入主题，不是没有任何后续点击。
