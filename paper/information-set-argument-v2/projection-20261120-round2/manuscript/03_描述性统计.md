N16 保留五层倒梯形，但把 484、3,000 小时、1,350 小时及 50 着色/加粗，蓝色代表总体、金色代表高匹配子样本。层宽只表示处理层级，不能解释为流失率。右侧为两个样本的说明：“484 户：估计总体投入与主题分布”；“50 户：研究 URL 大多能匹配股票代码，可以限定到所交易股票”。下句明确它是代码匹配子样本，不是只有 50 户能识别订单。总量约 3,000/1,350 小时保留约数，不改为样本筛选阈值。

N17 新增“研究内容与混合页面的归类”。上方约四成空间用分组列表完整列 11 类：风险统计、盈利、股利；其他基本面、分析师、知情持股；价格图、技术；公司官网、其他、未确定。下方三行表分别是综合行情快照、未确定新闻、留言板，说明用主题兴趣、RavenPack 新闻类别、Reddit 帖子主题作分配。突出“格式≠单一主题”。视觉权重在 N21 具体举例；此页不塞权重范围。

N18 保留原三组成对条与全部数值。公式中 i 为投资者（家庭），S 为纳入统计的股票范围；户内研究分钟/订单笔数，再跨户报告均值/中位数。底部两点必须可见：同一 50 户限定交易标的，96.8/51.7 变为 29.1/5.7；全部研究还包括未交易股票及部分难配码记录。另以短句“各口径均值明显高于中位数，投入呈右偏长尾”引出异质性。5.7 是跨户中位数，不是均值。

N19/20 沿用被认可的样本画像、跨站分布和主题双轴条图。N20 的股利直接均值回查 Table 3 原图；保留必要单位及来源，避免仅为统一文风改写事实。
