# 第一章 信息与行为资产定价：为什么要观察投资者获取了什么

## 1.1 模型需要信息输入，交易结果却不能还原输入

资产定价研究需要说明投资者怎样形成对未来收益和风险的判断。在Markowitz与Sharpe的经典框架中，风险及协方差决定组合选择的重要权衡；Hong–Stein的信息扩散框架区分新闻与价格模式的处理；盈利信号和收益外推模型又依赖不同的历史资料。这些设定影响信念如何变化、需求怎样形成，因而是经济机制的一部分。困难在于，研究者通常能够观察价格和交易，却较少直接观察个体形成判断之前获取了哪些信息。

从最终行动倒推信息输入并不容易。两位投资者都买入同一只股票，可能一位读了盈利预测，另一位只看了近期价格；即使都看过相同内容，也可能因为先验、解读和持仓不同而采取相反行动。交易记录把信息、解释与偏好共同作用后的结果呈现出来，无法单独辨认上游每一环节。若想知道某种信号是否符合现实中的投资者研究习惯，就需要直接观察获取过程的一部分。

这也是原论文从投资决策链条进入研究问题的原因。作者把获取信息、形成信念、结合偏好作出考虑、交易或配置组合区分开来。其中最难观察的一环，恰好是启动后续过程的信息获取。本文选择向这一环节推进，研究个体在可得资料中实际接触了什么。

这里需要区分两个层次的“信息集”。市场效率讨论价格反映了哪一类信息，个体研究讨论哪些人获取了哪些输入。市场价格可能吸收某项公开消息，同时很多散户没有读过它；少数参与者的价格发现，与其他人的有限信息获取可以并存。因此，本文与资产定价的联系来自对微观信息输入的刻画，不能仅凭散户访问了什么页面，就给市场是否有效下结论。

对行为金融而言，这种微观刻画尤其有用。价格外推模型需要知道人实际看到多长的历史窗口；强调盈利信号的模型需要了解盈利资料在研究中占什么位置；异质投资者模型则需要知道信息配置的差别主要发生在人与人之间，还是同一人面对不同股票时。原论文引言引用多种模型，是要说明这些设定尚有直接事实可以补充，而不是将每一类模型都列为本文即将检验的假说。

## 1.2 注意力文献的进展与内容层面的缺口

信息获取并非一个全新的经验议题。注意力文献已经建立了许多联系：新闻、异常成交和极端收益可能使某只股票进入散户视野；搜索强度可以帮助观察关注何时上升。这些研究让原本不可见的注意力变得可以测量，也使我们更清楚地理解股票如何进入投资者的考虑范围。

本文进一步追问的，是注意力内部由什么组成。知道某只股票的搜索量上升，并不能同时知道这些搜索者读了盈利、分析师意见还是价格图；知道一类信息与交易相关，也不足以衡量它相对于其他内容有多重要。不同研究使用不同代理变量，还使各项结果较难放在一个共同分母下比较。局部证据可以证明某种信息受到关注，却未必能还原一个投资者实际形成了怎样的内容组合。

因此，从注意力总量进入信息输入，需要联合观察三个对象。第一是内容，区分被关注的是哪种资料。第二是个体，判断总体内容分布是否只是少数高投入者的行为，还是多数家庭都如此。第三是交易情境，将研究放到具体行动的前后，而不是只知道某一天市场上有更多搜索。这三个对象共同出现，才可能同时讨论资源规模、内容构成和它们的分布。

最接近的前序工作是Gargano与Rossi的券商账户研究。它已经利用账户内活动研究注意力分配及其与绩效的联系，故本文的贡献不能概括为“首次使用点击流”。本篇扩展的关键，在于浏览记录覆盖券商之外的网站，URL还允许更细地识别内容，并将跨站活动放回同一户的轨迹。两类数据各有优势：账户数据更接近组合和绩效，跨站内容记录则更接近完整的在线研究过程。比较应落在可观察对象的差别上，而非笼统判断哪一份数据更好。

## 1.3 本文把哪些原本分散的对象放到一起

本文的核心问题可以表述为：在现实的在线研究环境中，个体投资者获取了多少、什么样的信息，这些输入又怎样随股票、投资者和交易情境而变化？它不是用一个总指标替代全部研究，也不是从访问记录直接估计投资者如何更新信念。作者首先建立一套能够容纳这些比较的共同记录，再逐步刻画信息获取过程。

这样的研究设计有独立价值。假如价格资料在可见研究中最突出，理论就需要认真考虑投资者实际看到的历史片段及其展示方式；假如内容配置存在较大个体差异，使用一个代表性研究者描述所有散户便会损失重要信息。事实并不自动选出唯一模型，但会使一些输入设定获得更强的经验依据，也使另一些设定需要补充解释。

这种增量尤其体现在总体与个体的区别上。大量价格研究可以来自人人略看，也可以来自少数家庭反复查看；同样的合计分钟因而对应不同的信息分布。联合记录让这些情形有机会被分开，而仅有一个市场搜索总量时，两者很容易混在一起。下一章先说明浏览面板来自哪里、记录包含哪些字段，以及一条页面地址凭什么能够连接内容、股票和交易；具体测量维度在这个对象建立之后展开。
