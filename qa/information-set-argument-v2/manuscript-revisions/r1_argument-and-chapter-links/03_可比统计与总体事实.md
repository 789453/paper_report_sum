# 第三章 可比统计与总体事实：研究资源有多少，又被放到了哪里

## 3.1 从浏览时间到家庭研究比率

信息获取的第一个经验问题，是普通投资者究竟投入了多少资源。研究量先需要一个与信息获取相符的口径：登录、账户余额、持仓查看和输入订单消耗时间，却未必提供本文定义的股票资料，作者将其另报为非研究金融浏览。已识别的宏观、行业信息可以进入宽口径研究分类；公司网站活动则需要同股的其他投资研究作旁证，并设时间上限，以减少购物和一般业务被计入。分类的任务是让“研究分钟”尽量对应研究行为。

之后还需解决比较单位。面板是滚动的，家庭被观察一到四个月不等，交易频率也不同。如果只比较总分钟，停留更久或交易更多的家庭会机械地得到更大数值。论文分别按月份和交易次数归一，再在家庭之间汇总。本文最常被引用的每次交易研究量，采用后一种归一方式。

令家庭i的观察期研究总时间为Tᵢ，观察到的交易数为nᵢ，则其研究比率为：

\[
r_i^{\mathrm{all}}=\frac{T_i^{\mathrm{all}}}{n_i},\qquad
r_i^{\mathrm{traded}}=\frac{T_i^{\mathrm{traded}}}{n_i}.
\]

前一个分子包含样本期研究过的内容，后一个只保留与该家庭样本期已交易股票相联系的研究。论文在户内先得到这个比率，再计算家庭横截面的均值或中位数。所有家庭至少有一笔被识别交易，分母为正。均值是各户比率的平均，不是把全体家庭分钟相加后除以2911；中位数描述家庭比率的中间位置，也不是把所有交易逐笔排序。

另一个容易混淆的词是“全部研究”。它不等于只研究市值前1000股票，也不表示观察到每一种投资信息。它是本文识别框架内的宽口径研究，包含交易与未交易股票，少量内容还涉及指数、基金、期权等。市值前1000的范围只在后文股票回归中使用。

股票匹配精度决定可以使用哪个分子。全样本484户最适合统计总体研究；如果某些链接缺股票，时间仍可计入总量。要把研究归到已交易股票，就需要更高的股票匹配率，因此作者使用50户子样本。作者报告其总体研究量、交易频率和可观察人口特征与全样本大体相近。这个比较支持子样本的用途，同时不能把50户与484户的估计随意拼成同一个人的研究过程。

## 3.2 典型家庭与高投入家庭：总量分布和跨平台覆盖

在对象明确之后，Table 2呈现出第一组重要事实：研究量在家庭间高度不均，典型家庭与高投入家庭的差别很大。

|研究范围与样本|均值：分钟/交易|中位数：分钟/交易|
|---|---:|---:|
|484户：宽口径全部研究|144.2|36.4|
|50户高匹配样本：宽口径全部研究|96.8|51.7|
|同一50户：样本期已交易股票相关研究|29.1|5.7|

来源：Table 2 Panels B–C，p.47。各列是家庭内比率的横截面统计。

约六分钟来自最后一行的5.7。它表示典型家庭在已交易股票上的可见研究，以该户交易次数归一后很有限；分子包括观察期内相关研究，并不只取下单前几分钟。是否集中在交易前，是后面事件时间分析要单独回答的问题。将总量与时点分开，才能理解两类结果各自增加的认识。

均值29.1远高于中位数5.7，说明少数家庭投入较多。全样本的每月研究时间也表现出同样的右尾：均值118.0分钟、中位数37.1分钟，95分位为530.4分钟。因而，使用均值描述“典型投资者”会突出重度研究者；只报中位数又会掩盖大量研究实际由这些家庭承担。二者都需要保留，因为典型行为和总体信息生产并非同一个问题。

宽口径研究又明显多于已交易股票相关研究。这里既有研究后没有在观察期交易的股票，也有不能完整归到已交易标的的内容。研究并不总是以当期交易结束：它可能扩展考虑集合，也可能是持续跟踪。不能把36.4与5.7直接相减解释为“典型家庭在未交易股票上花了多少时间”，因为它们来自不同样本，而且分位数不具备这种可加性。

跨平台覆盖进一步解释了为什么不能只看券商账户。全样本均值家庭每次交易对应55.7分钟券商内研究，而Yahoo Finance和其他非券商财经来源分别为45.3与41.9分钟，另有少量公司网站研究。对于明显影响均值的高投入家庭，站外活动占据相当重要的位置。作者将券商内研究与前序点击流研究比较时得到较接近的日均量级，这有助于把差异定位到覆盖范围，而非笼统说旧数据低估所有行为。

到这里我们知道了投入多少及其分布，仍不知道投入在经济意义上意味着什么。研究半小时价格图，与研究半小时盈利和资产负债表，形成的信息输入并不相同。下一步需要打开总量内部的内容构成。

## 3.3 内容配置：价格图、分析师与风险信息

Table 3同时报告研究时间和是否曾研究某类内容。二者互补：看一眼机构持仓比例可能很快，阅读财务报告可能较慢；仅比较分钟会混合信息呈现方式与参与程度。参与比例则说明这一类输入是否进入了家庭的可见研究范围。

|直接识别的页面/主题|有非零研究时间的家庭比例|全样本均值：分钟/交易|
|---|---:|---:|
|价格图|93%|39.1|
|综合行情Snapshot|93%|37.0|
|内容不明新闻|85%|16.2|
|分析师资料|71%|12.5|
|其他基本面|53%|2.6|
|盈利|40%|1.7|
|风险统计|约1%，7户|0.0，四舍五入|

来源：Table 3左侧直接分类，p.48；7户见p.24。分母是484户，时间包括宽口径研究，不是仅限已交易股票。某户可以研究多类内容，比例不能加成100%。

价格图是最大的单项专门研究内容，综合行情同样广泛，分析师资料在可辨经济主题中也很常见。与之相比，直接钻取beta或波动率页面的家庭极少。这些差别使信息输入具有明显方向性：公开资料的菜单相当丰富，实际研究却没有平均分配到每一种规范上重要的指标。

但综合行情并非单一信号。它通常同时提供价格、价格图、盈利、分红等条目，新闻与讨论板也可能涉及多个主题。若只保留页面名称，可以准确说明访问了哪类页面，却不能完整比较底层经济内容。作者因而另作内容归因。Snapshot按可直接观察到的主题参与兴趣分配，新闻利用可匹配标题及RavenPack分类估计内容，讨论板借助当代r/stocks内容分布。等权和展示比例是Snapshot的替代分配方式。归因后的时间仍来自同一批记录，改变的是内容分配。

这一处理并非边角问题：Snapshot、内容不明新闻与讨论板的全样本均值合计60.4分钟，即37.0＋16.2＋7.2，约占144.2分钟的42%。在主表采用的归因口径下，价格图对应64.4分钟，分析师18.6分钟，盈利10.6分钟，风险统计1.8分钟。前者是最大内容项，不能写成“价格图单独占去绝大多数时间”；64.4÷144.2约为44.7%。直接访问与归因两种结果应分别解释，第五章将讨论归因权重是否强化了已观察的内容结构。

价格信息的进一步细节是历史窗口。Figure 1把含默认显示的图表与主动改动窗口的图表分开。前者超过70%展示日内历史；当投资者主动改变默认时，更常选择一月至一年。这意味着实际接触的短历史，可能同时反映平台先呈现了什么，以及用户是否愿意继续调整。观察到日内图表频繁出现，并不能单独识别投资者稳定偏好的预测期限。

风险统计也应放回这种内容环境理解。原文指出，价格图本身可能传递波动等风险线索。因此，专门风险页面少访问，最直接说明标准化风险统计不是常被主动钻取的输入；风险判断是否转而依赖图形、经验或其他线索，是一个有根据的解释问题。本文没有直接测量这种替代关系，也不能据此认定投资者完全不考虑风险。

总量与内容共同形成了一个更具体的画像：家庭之间的投入差距很大，研究时间相当一部分发生在券商之外，内容配置明显偏向价格资料及综合行情。这仍是总体画像。它可能由某些股票更受关注形成，也可能由不同家庭的研究习惯形成；相同内容总量还可能对应不同交易时点。下一章据此进入股票、家庭与交易情境的比较。
