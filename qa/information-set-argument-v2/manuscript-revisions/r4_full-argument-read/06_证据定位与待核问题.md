## 保留的未决问题

1. Table 4的投资者覆盖比例分母未在表注明确到可完整复现的程度。本稿不将“当月在样本家庭”或“固定484”中的一个当成已核实算法。
2. Table 4短面板中的Newey–West排序、窗口与跨股票相关性处理，公开说明不足以复现；这不等于已经证明作者标准误错误。
3. Table 5的输入家庭数、标准化细节及Speculative Stock Focus精确权重需作者代码。正文p.35称研究倾向，表注p.51称交易倾向，本文保持中性名称。
4. 正文p.24将新闻概括为present-day RavenPack分布，附录p.67具体描述两家券商的标题、股票与日期匹配。本文按附录解释实际可见流程，不将某一概括扩大为所有新闻都使用当代样本。
5. IA1明确为构造例，且p.59文字与表内sell地址的方向不一致。按地址解释，不把它当作真实买卖记录。
6. 原论文说Snapshot替代归因不会明显改变结果，但未完整披露每套最终Table 3统计；未自行填稳健性区间。个体输入和作者代码本轮未取得。

未决问题集中保存在此，避免把每一项复现细节反复写进研究叙述。正文仍保留会改变主要解释的条件。
