## 第二遍：用实际 PPT 与原论文修正指令的对象

1. M9 是章节页、M10 才是数据页。因此“网页轨迹”在 M9 改词，数据可视化与 M10 标题统一落实到 M10，避免重复新建数据页。
2. “没有交易数据”按 P 的实际含义写成“没有后台成交确认与完整持仓”；URL 仍识别推定订单，不能把 2,911 笔的来源删没。
3. “高质量 50 户”是**研究 URL 的股票代码匹配率很高**，不是从 484 户中挑 50 户表现好的投资者，也不是只有 50 户能识别交易。P18–19；Table 2 C。
4. “研究分位数降低”是**同一 50 户、全部研究与所交易股票研究**两个口径的比较，不是分位数估计被修正。主要包括研究未交易股票，另有难配码记录；不能把所有差额说成市场综合浏览。均值 29.1、中位数 5.7；“每笔约六分钟”须明确是中位数，不是均值。
5. “一致性/意志性”在右尾、跨股票与跨投资者段恢复为**异质性**；在模型记分卡中则保留“与输入假设一致”。不批量替换成同一个词。
6. P32 确实说面板过短，不足以设置公司固定效应。上屏保留行业固定效应；股票层回归既不是因果识别，也不是投资者固定效应分解。
7. M28 的 0.079 与 0.090 分属 Table 4 (5)/(6)，故写 7.9% / 9.0%，口述“约 8%–9%”。不能图用 (6) 却只报 8%。低 R² 只提供转向投资者层的动机；结合 Table 5 才讨论研究风格，不直接宣称“主要由个人解释”。
8. PCA 的 B_ik 是**投资者 i 在主题 k 的月均研究分钟严格大于 2**，只使用匹配到股票的研究，然后跨股票汇总；不是每个投资者×每只股票×月份单元超过 2 分钟。P35 / Table 5。矩阵的 0/1 必须标“教学构造例”，不能当作未公开微观数据。
9. M19 的视觉拆分是 Table IA2 的**备选视觉权重**；Table 3 的 39.1→64.4 使用**兴趣权重**。页面必须说明这一区别，不能以真实网页截图反推当年权重或称 64.4 来自像素面积。
10. 第三条 URL 按 IA1 第 7 行逐字段核对，保留 `showQTRChange`、`display`、`overlay`、`indicator`、`duration`、`daysforward`、`year`。券商域名原文即匿名，不能编造成真实券商域名。
11. M25 没有可取得的微观散点；新图用 Table 4 原系数与 t 值重绘覆盖率和总用时结果，下一页再解释 R² 与经济量级，不伪造散点云。
