# 模板来源、架构与修改入口

## 原始模板已下载

- 用户指定的 [Overleaf 页面](https://cn.overleaf.com/latex/templates/ruc-beamer-theme/ssryphkjpyjt)。页面预览 PDF 保存在 `sources/ruc_overleaf_original.pdf`。
- 模板作者 [GohUnTsuan/RUC-Beamer-Theme](https://github.com/GohUnTsuan/RUC-Beamer-Theme) 的完整 Git 仓库保存在 `vendor/RUC-Beamer-Theme/`。
- 额外归档了 [Beamer 官方源码](https://github.com/josephwright/beamer)、[社区 Beamer skill](https://github.com/wenlzhang/beamer-skill) 及诊断期间使用的 CTeX-kit 历史源码。生产编译使用本机已安装的 Beamer，并没有用新下载的类文件覆盖系统。

Overleaf 页面标 CC BY 4.0；GitHub 仓库提供 MIT LICENSE。项目保留原始出处与各自许可，不将两个分发渠道的许可混称。交付压缩包中直接使用的 `RenminUniv.sty` 来自 GitHub 仓库，附带该仓库 MIT 许可。

仓库中没有单独命名的“无水印版”。水印由 `RenminUniv.sty` 末尾的 `background` 模板加载 `pic/background.pdf`。本项目加载原主题后，在派生层清空背景；封面也不插入独立校徽。因此交付的是有改动记录的无水印派生版。

## 四层结构

| 层 | 文件 | 作用 |
|---|---|---|
| Beamer 类 | 本机 Beamer；官方源码另归档 | frame、计数、引用、导航、notes |
| 原始 RUC 主题 | `RenminUniv.sty` | smoothbars、圆点、酒红配色、标题和页脚 |
| 本地派生设置 | `ruc-research.sty` | 中文字体、无水印、主附录计数、表格列、页脚对比度 |
| 论文内容 | `paper/information-set-argument-v2/main.tex` | 中文讲述、公式、表格、原始图像、隐藏讲者备注 |

保留的视觉特征：4:3、RGB(151,31,48)酒红、smoothbars和圆点导航、中文楷体。调整的特征：取消背景及封面校徽、取消每节重复目录、封面不编号、附录独立计数、关闭多余导航按钮、修正页眉页脚内部超链接的文字对比度。

## 中文字体与实际编译环境

实际方案是 XeLaTeX + fontspec + xeCJK。Windows优先KaiTi，其他环境回退FandolKai；Latin Modern用于英文字体与数学。楷体粗体采用明确的合成粗体设置，避免找不到粗体字体时静默替换。字号随Beamer的页面物理尺寸缩放，不能直接与16:9 PowerPoint的点数比较。

首次尝试CTeX时发现：本机zhnumber3.1要求较新的expl3，而本机内核为2024年版本。当前报告不需要CTeX的中文章节数字与日期宏，因此在本地派生层直接采用xeCJK，并设置“图”“表”名称。系统宏包没有被修改。这个取舍已写入skill的技术说明。

## 本地编译

在项目根目录执行：

```powershell
$env:PYTHONUTF8='1'
python scripts/build.py minimal
python scripts/build.py paper
python scripts/verify_argument_v2.py
python scripts/check_and_render.py
```

只修改正文时，编辑`main.tex`后运行paper构建；`build.py`仅在目标缺少主题时复制通用依赖。直接复制整个论文工程目录后，也可以在该目录运行两遍：

```powershell
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

构建脚本检查最终一遍日志中的缺字、未定义引用、字体替代和h/vbox溢出。还需要运行PDF验收及看渲染图，不能只依赖退出码。

## Overleaf 使用

上传交付的无水印模板ZIP或论文源码ZIP，选择XeLaTeX、主文件`main.tex`。模板包是5页功能样例；当前论文源码是46页工作基线。首次在不同TeX环境中使用仍应重新编译并检查，尤其是字体回退。没有声称已经登录Overleaf账户进行云端构建。

## 常见修改

- 换论文：从`reusable/`复制最小模板到新的独立paper目录，修改标题、正文和引用，重新核对证据。
- 换图片：在`assets/`放PDF/PNG/JPG，使用宽高双限制与`keepaspectratio`。
- 长公式：用`aligned`拆行；先解释符号，不把整段论文公式缩成图片。
- 长表：删去非核心行列或拆到附录；保留原表定位，禁止编造未报告统计量。
- 16:9：这是明确的版式变更，在documentclass加入`aspectratio=169`后必须全套重排和验收。本次保留原4:3。
- 编号：使用LaTeX的caption/label/ref；报告内编号与原论文编号应分开，来源栏另给原论文编号。

最小样例覆盖中英文、上下标、编号公式、三线表、TikZ矢量图、交叉引用以及A1/1附录页码，可作为以后修改主题后的第一轮检查。
